위라클랩 개인정보처리방침 (Privacy Policy)

주식회사 위크레잇(이하 '회사'라고 합니다)은 정보주체의 자유와 권리를 보호하기 위해 「개인정보 보호법」 및 관계 법령, 그리고 Google API Services User Data Policy를 준수하여, 적법하게 개인정보를 처리하고 안전하게 관리하고 있습니다. 이에 따라 정보주체에게 개인정보 처리에 관한 절차 및 기준을 안내하고 다음과 같이 개인정보 처리방침을 수립·공개합니다.

1. 수집하는 개인정보의 항목 및 수집 방법

회사는 원활한 서비스 제공을 위해 아래와 같은 개인정보를 수집 및 처리하고 있습니다.

  • 필수 수집 항목: 성명, 연락처(휴대전화번호), 이메일 주소
  • 자동 수집 항목: 서비스 이용 기록, 접속 로그, 쿠키, 접속 IP 정보
  • 구글 API 연동 시 수집 및 접근 항목 (이용자 명시적 동의 시): 구글 계정 식별자, 이메일 주소, 프로필 정보, 구글 드라이브 앱 생성 파일 접근 권한 (drive.file), 구글 캘린더 일정 등록 권한 (calendar.events)

2. 구글 사용자 데이터 취급 및 정책 준수 (Google User Data Policy)

[Google API 서비스 사용자 데이터 정책 준수 선언]
위라클랩의 Google API를 통한 사용자 데이터의 사용 및 다른 앱으로의 이전은 Google API 서비스 사용자 데이터 정책 (Limited Use 요구사항 포함)을 엄격히 준수합니다.

1. 필수 목적 한정 사용: Google API를 통해 수집되거나 연동된 사용자의 구글 드라이브 및 캘린더 데이터는 오직 사용자가 요청한 고객 관리 시트 템플릿 생성 및 일정 알림 등록(서비스 제공 목적)으로만 사용됩니다.
2. 제3자 제공 및 판매 금지: 회사는 Google API를 통해 얻은 어떠한 사용자 데이터도 광고 플랫폼, 데이터 브로커 등 외부 제3자에게 판매하거나 제공하지 않습니다.
3. AI/ML 학습 배제: Google API를 통해 획득한 사용자 데이터는 어떠한 형태의 일반 인공지능(AI) 또는 머신러닝(ML) 모델의 학습, 개발, 개선에도 일절 사용되지 않습니다.

3. 민감 데이터에 대한 기술적·관리적 보안 보호 조치 (Data Protection Mechanisms)

회사는 구글 사용자 데이터를 포함한 모든 이용자의 정보가 분실, 도난, 유출, 변조 또는 훼손되지 않도록 다음과 같은 구체적이고 강력한 기술적·물리적·관리적 보안 메커니즘을 적용하고 있습니다.

(1) 전송 중 데이터 암호화 (In-Transit Encryption)

이용자의 웹 브라우저와 위라클랩 시스템, 그리고 Google API 서버 간에 전송되는 모든 데이터는 최신 표준 보안 전송 계층 프로토콜인 HTTPS (TLS 1.2 또는 TLS 1.3) 암호화 통신 채널을 통해서만 전송됩니다. 공공 네트워크 구간에서도 패킷 감청이나 데이터 위·변조가 원천 차단됩니다.

(2) 데이터 저장 최소화 및 브라우저 런타임 처리 (Data Minimization & Storage Protection)

구글 스프레드시트 및 드라이브 파일의 상세 데이터는 사용자의 브라우저 클라이언트 런타임 메모리(In-Memory) 상에서만 직접 처리되며, 당사의 백엔드 서버 데이터베이스에 영구적으로 복제하거나 별도 저장하지 않습니다. 세션 유지를 위한 임시 토큰은 이용자의 로컬 브라우저 보안 스토리지에만 국한되어 보관됩니다.

(3) 엄격한 접근 통제 및 관리적 보안 (Access Control & Administrative Safeguards)

회사는 서비스 운영 인력을 포함한 어떠한 내부 직원도 이용자의 구글 드라이브 파일 및 개인 고객 데이터에 직접 접근할 수 없도록 엄격한 역할 기반 접근 제어(RBAC) 및 시스템 접근 차단 정책을 시행하고 있습니다.

(4) 데이터 보유 기간 및 즉시 파기 절차 (Data Retention & Deletion)

Google API 인증 정보는 이용자가 서비스 내에서 연동 해제 버튼을 클릭하거나 회원 탈퇴를 요청하는 즉시 영구 파기됩니다. 또한 이용자는 언제든지 구글 계정 보안 권한 관리 페이지에서 위라클랩에 부여한 구글 권한을 직접 즉시 철회할 수 있습니다.

Data Protection Disclosures (for Google API Verification Reviewers)

WERACLE LAB implements comprehensive technical and operational safeguards to protect sensitive user data obtained through Google APIs:

  • Encryption in Transit: All data transmitted between the client, application, and Google APIs is fully encrypted using industry-standard HTTPS with TLS 1.2/1.3.
  • Data Minimization & Storage: Google user data (including spreadsheet contents and Drive files) is processed strictly in-memory within the client browser. No user spreadsheet data is persistently copied, stored, or cached on WERACLE LAB's backend servers.
  • Access Control: Zero-access policy applies to internal personnel. Internal staff cannot access, view, or modify user Google Drive and Spreadsheet data.
  • Prohibition on AI/ML Training: Google user data is NEVER used to train, develop, or improve generalized AI/ML models.
  • No Third-Party Transfer or Sale: User data is never sold, transferred, or disclosed to third parties, advertising networks, or data brokers.
  • Data Deletion & Revocation: Users can revoke access at any time via Google Security Settings (myaccount.google.com/permissions) or through the in-app disconnect option, which immediately invalidates all active tokens.

회사는 수집한 개인정보를 다음의 목적을 위해 활용합니다.

  • 회원 관리: 서비스 이용에 따른 본인확인, 개인 식별, 불량회원의 부정이용 방지, 민원처리 및 고지사항 전달
