# 위라클랩 인증 및 로그인 모듈 (Auth & Login Module)

본 폴더는 위라클랩의 **로그인, 로그인 상태 디자인, 로그인 상태 클릭 시 노출되는 프로필/마이페이지** 관련 전체 자산을 독립 패키징한 모듈입니다.

---

## 1. 파일 구성 및 역할

| 파일명 | 역할 및 설명 |
| :--- | :--- |
| **intro.html** | **로그인 메인 화면**: 로그인 버튼 클릭 시 연결되는 심플 구글 원클릭 로그인 페이지 (심플 멘트 및 미니멀 카드 레이아웃) |
| **auth.js** | **인증 및 세션 엔진**: Supabase 세션 감지, 구글 소셜 로그인, 자동 권한 승급, 회원 등급(basic, vip, family, manager), 모바일 팩스 쿼터 및 D-Day 계산 로직 |
| **auth_profile_style.css** | **로그인 및 프로필 스타일시트**: 로그인 카드, 회원 등급 뱃지(badge-pro, badge-basic 등), 프로필 아바타 및 헤더 드롭다운 전용 스타일 |
| **mypage.html** | **로그인 상태 상세 페이지**: 로그인 상태(헤더 프로필) 클릭 시 나오는 마이페이지 (내 정보, 소속 지사, 구독 플랜 현황, 팩스 잔여 횟수, 로고 관리) |
| **config.js** | **Supabase 환경 설정**: 데이터베이스 클라이언트 초기화 및 글로벌 인증 이벤트 버스 선언 |

---

## 2. 주요 동작 흐름

1. **로그인 버튼 클릭 시**:
   - 상단 헤더 우측 [로그인] 버튼 클릭 시 심플한 'intro.html' 화면이 노출됩니다.
   - 불필요한 홍보/FAQ 요소 없이 기본 안내 멘트와 [Google 계정으로 로그인] 버튼으로 즉시 간편 로그인이 진행됩니다.

2. **로그인 상태 디자인 (헤더)**:
   - 로그인 완료 시 헤더 우측에 사용자 프로필 아바타, 닉네임, 등급 뱃지(VIP/일반)가 표시됩니다.

3. **로그인 상태 클릭 시 (드롭다운 & 마이페이지)**:
   - 로그인된 프로필 영역 클릭 시 전용 드롭다운 메뉴가 열립니다.
   - '마이페이지' 클릭 시 'mypage.html'이 로드되어 상세 회원 정보와 구독 상태를 확인할 수 있습니다.
