주식회사 위크레잇(이하 '회사'라 함)은 정보주체의 자유와 권리를 보호하기 위해 「개인정보 보호법」 및 관계 법령, 그리고 Google API Services User Data Policy를 엄격히 준수하며, 이용자의 개인정보를 안전하게 처리하고 있습니다. 본 개인정보처리방침은 회사가 제공하는 위라클랩(WERACLE LAB) 서비스(웹 및 모바일 웹 애플리케이션)에 적용됩니다.

1. 수집하는 개인정보의 항목 및 수집 방법

회사는 원활한 서비스 제공을 위해 최소한의 개인정보만을 수집 및 처리합니다.

  • 일반 회원가입 및 프로필: 성명, 연락처(휴대전화번호), 이메일 주소, 직책, 소속 회사명, 프로필 사진 URL, 개인/회사 로고 URL
  • 서비스 이용 중 자동 생성·수집: 서비스 이용 기록, 접속 로그, 쿠키(Cookie), 접속 IP 정보
  • Google API 연동 시 수집 및 접근 항목 (이용자의 명시적 동의 시에 한함):
    • 구글 계정 기본 식별 정보: 구글 계정 ID(고유 식별자), 이메일 주소, 프로필 정보
    • 구글 드라이브 파일 접근 권한 (drive.file): 위라클랩 앱을 통해 사용자가 직접 생성하거나 선택한 고객관리 스프레드시트 파일에 대한 접근 권한
    • 구글 캘린더 일정 등록 권한 (calendar.events): 위라클랩 앱을 통해 사용자가 등록을 요청한 상담 일정 및 보험 만기 알림 이벤트 생성 권한

2. 구글 사용자 데이터 취급 및 정책 준수 (Google User Data Policy)

WERACLE LAB's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
[Google API 서비스 사용자 데이터 정책 준수 핵심 원칙]

1. 필수 목적 한정 사용 (Limited Use): Google API를 통해 획득한 모든 사용자 데이터는 오직 이용자가 요청한 고객 관리 시트 생성 및 상담 일정 등록 등 위라클랩 서비스 본연의 핵심 기능을 제공하기 위한 목적으로만 사용됩니다.
2. 제3자 제공 및 판매 절대 금지: 회사는 Google API를 통해 획득한 사용자 데이터를 어떠한 경우에도 광고 플랫폼, 데이터 브로커, 정보 중개업자 등 외부 제3자에게 판매하거나 제공, 이전하지 않습니다.
3. AI/ML 모델 학습 배제: Google API를 통해 접근한 사용자 데이터는 어떠한 형태의 인공지능(AI) 또는 머신러닝(ML) 모델의 학습, 개발, 개선 목적으로도 일절 사용되지 않습니다.
4. 인간 개입 차단 (Zero Human Access): 회사의 임직원을 포함한 어떠한 운영 인력도 이용자의 구글 드라이브 파일 내용이나 캘린더 일정 데이터에 직접 접근하거나 열람할 수 없습니다.

4. 민감 데이터에 대한 기술적·관리적 보안 보호 조치 (Data Protection Mechanisms)

회사는 구글 사용자 데이터를 포함한 모든 이용자 데이터의 안전성 확보를 위해 다음과 같은 기술적·관리적 보안 메커니즘을 시행하고 있습니다.

(1) 전송 중 데이터 암호화 (Encryption in Transit)

이용자의 브라우저와 위라클랩 시스템, 그리고 Google API 엔드포인트 간에 송수신되는 모든 데이터 트래픽은 업계 표준 보안 전송 계층 프로토콜인 HTTPS (TLS 1.2 또는 TLS 1.3) 암호화 채널을 통하여 보호됩니다. 비암호화(HTTP) 평문 통신은 전면 차단되어 중간자 공격(MITM) 및 도청을 원천 방지합니다.

(2) 데이터 최소화 및 클라이언트 인메모리(In-Memory) 처리 원칙

구글 스프레드시트의 고객 명단 데이터 및 캘린더 상세 내용은 이용자의 브라우저 로컬 런타임 메모리 상에서만 즉시 처리됩니다. 회사의 백엔드 서버나 제3자 클라우드 데이터베이스에 이용자의 구글 드라이브 파일 본문이나 캘린더 데이터가 영구적으로 보관되거나 백업되지 않습니다.

(3) 엄격한 접근 제어 및 권한 관리 (Access Control)

구글 API 토큰 정보는 세션 유지를 위한 임시 토큰 형태로만 이용자 브라우저 세션에 국한되어 관리되며, 서비스 운영자나 내부 직원이 이용자의 개인화된 구글 파일이나 일정 데이터에 접근할 수 있는 기술적 통로를 두지 않습니다.

(4) 구글 데이터 삭제 및 연동 해제(철회) 절차 (Data Deletion & Revocation)

  • 즉시 연동 해제: 이용자는 위라클랩 서비스 내 [구글 연동 해제] 버튼을 통해 언제든지 토큰을 폐기하고 연동을 즉시 종료할 수 있습니다.
  • 구글 계정을 통한 직접 권한 철회: 이용자는 언제든지 구글 계정 보안 설정 (myaccount.google.com/permissions)에 접속하여 위라클랩에 부여된 구글 접근 권한을 즉시 직접 철회할 수 있습니다. 권한 철회 즉시 위라클랩은 해당 계정의 구글 데이터에 일체 접근할 수 없게 됩니다.
  • 계정 탈퇴 및 데이터 완전 삭제 요청: 서비스 회원 탈퇴 시 보관된 기본 계정 정보는 지체 없이 영구 파기되며, 개인정보 보호책임자(iart48@naver.com)에게 이메일로 요청 시 24시간 이내에 데이터 삭제 조치가 완료됩니다.

Data Protection Disclosures (for Google API Verification Reviewers)

WERACLE LAB's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Scope Compliance: WERACLE LAB requests only two Google API scopes: drive.file and calendar.events. Access is strictly limited to files and events directly created or managed through our application.
  • Encryption in Transit: All communications between the client browser, WERACLE LAB, and Google API servers are encrypted using modern HTTPS (TLS 1.2/1.3).
  • Zero Server-Side Storage: Google user data (spreadsheet rows, Drive files, and calendar items) is processed entirely in-memory within the client's web browser. WERACLE LAB does NOT store, cache, or duplicate Google user content on its backend servers.
  • No AI/ML Training: Data obtained via Google APIs is strictly excluded from being used to train, develop, or improve generalized AI/ML models.
  • No Third-Party Sharing or Sale: User Google data is never shared with, sold to, or distributed to advertising networks, data brokers, or third-party platforms.
  • User Revocation & Deletion: Users can revoke permissions at any time via Google Account Permissions or in-app disconnect. In-app data is permanently invalidated upon revocation or account deletion.
