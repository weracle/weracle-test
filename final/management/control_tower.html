⚠️ 삭제 후 새로고침 시 회원이 다시 나타나는 원인
수파베이스 profiles 테이블에 Row Level Security (행 보안 RLS)가 기본 활성화되어 있어, 일반 브라우저 키로는 타인 계정의 삭제/수정이 DB에서 무시됩니다.
아래 방법 1(가장 추천) 또는 방법 2 중 하나만 진행하시면 즉시 영구 삭제 및 등급 변경이 DB에 100% 반영됩니다.
방법 1. 수파베이스 SQL 1줄 실행 (가장 추천 / 30초 완료)

수파베이스 대시보드 ➔ SQL Editor ➔ 새 쿼리창에 아래 코드를 붙여넣고 [RUN]을 누르시면 RLS가 해제되어 자유롭게 삭제/수정됩니다. 

ALTER TABLE public.profiles DISABLE ROW LEVEL SECURITY;
방법 2. 마스터 Service Role Key 직접 입력

수파베이스 Project Settings ➔ API ➔ Project API keys ➔ service_role (secret) 키를 입력하시면 브라우저에서 슈퍼 관리자 모드로 즉시 삭제를 실행합니다.
