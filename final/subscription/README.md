# 위라클 구독 및 결제 서비스 모듈 (weracle_subscription)

본 폴더는 위라클 멤버십 구독 및 결제와 관련된 모든 기존 자산을 한곳에 정리한 통합 작업 공간입니다.

---

## 1. 파일 구성 및 역할

| 파일명 | 종류 | 역할 설명 |
| :--- | :--- | :--- |
| **`subscription.html`** | 상품 안내 랜딩 | 3가지 구독 플랜(올인원/CRM/인사이트) 혜택 및 가격 소개 페이지 |
| **`apply.html`** | 신청 및 결제 상세 | 3단계 워크플로우, 이용약관, 취소/환불 규정, 결제 신청 페이지 |
| **`payment_widget.html`** | PG 결제 위젯 | 토스페이먼츠(Toss Payments) 정식 SDK 결제 수단/약관 모듈 |
| **`api/subscribe.js`** | 백엔드 API | Supabase 유저 토큰 검증, 결제 이력 저장, VIP 회원 등급 자동 승급 |

---

## 2. 현재 정의된 구독 상품 및 요금제

1. **올인원 패키지 (ALL-IN-ONE)**: 월 34,900원
   * 위라클랩 CRM 고객관리 프로그램 이용권
   * 월간 보험 소식지 제공
   * 한장 비교 데이터맵 제공
   * 핵심 세일즈 전략 제공

2. **고객관리 프로그램 (CRM PLAN)**: 월 19,900원
   * 위라클랩 CRM 이용권 단독 제공

3. **보험 인사이트 (INSIGHT PLAN)**: 월 19,900원
   * 소식지 + 데이터맵 + 세일즈 전략 제공

4. **단건 결제 상품 (`apply.html` 내)**
   * 이미지 브랜딩: 200,000원 (퍼스널 네이밍 + 시그니처 로고)
   * 영업 마켓: 유료 서식/바인더 (준비 중)

---

## 3. 결제 흐름 (Workflow)

```
[subscription.html] (플랜 선택 및 구독 신청)
         ↓
    [apply.html] (상품 상세, 약관 동의 및 결제 금액 확인)
         ↓
[payment_widget.html] (토스페이먼츠 카드/간편결제 창 호출)
         ↓
 [/api/subscribe] (Supabase DB 저장 및 유저 등급 'VIP' 자동 승급)
```
