# hiddenclaim (숨은보험금 모듈)

국세청 홈택스 연말정산 간소화(의료비 G0003, 보장성보험 G0001) 실데이터 기반 미청구 실손보험금 및 숨은보험금 정밀 분석 모듈입니다.

---

## 1. 파일 구성 및 역할

| 파일명 | 역할 및 설명 | 수정 시점 |
| :--- | :--- | :--- |
| **`index.html`** | 숨은보험금 대시보드 화면 (UI/UX) | 화면 디자인, 버튼 위치, 텍스트 문구를 바꿀 때 |
| **`claim_engine.js`** | 1~5세대 실손 약관 공제 및 계산 엔진 | 세대별 자기부담금, 소액 공제 기준을 수정할 때 |
| **`hyphen_parser.js`** | 하이픈 API 실제 응답 JSON 정규화 파서 | 하이픈 응답 필드(anulAmt2 등) 매핑을 변경할 때 |

---

## 2. 깃허브(GitHub) 배포 안내

- 본 `hiddenclaim` 폴더를 깃허브 저장소 루트에 그대로 업로드하면, 웹 브라우저에서 `https://[내도메인]/hiddenclaim/` 접속 시 자동으로 `index.html`이 실행됩니다.
- 메인 홈페이지(`index.html`)에서는 `<a href="hiddenclaim/">숨은보험금 찾기</a>` 링크로 연결하시면 됩니다.
- 숨은보험금 관련 기능을 수정할 때는 다른 폴더에 영향을 주지 않고 오직 이 `hiddenclaim` 폴더 안의 파일만 수정하시면 됩니다.
